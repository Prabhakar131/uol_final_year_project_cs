# Benchmark Experiments

This folder contains one-off benchmark diagnostics and scenario-specific scripts.

Use the maintained runners in `notebooks/model_benchmarks/` for normal report
generation:

- `security_model_evaluation.py`
- `stt_model_evaluation.py`
- `coach_model_evaluation.py`
- `vlm_model_evaluation.py`
- `run_benchmarks.py`

Experiment outputs should be written to
`notebooks/model_benchmarks/results/experiments/`.
